## Build Phases

### ✅ Phase 0 — Infrastructure (Week 1–2)
```bash
# Run on fresh Contabo VPS (Ubuntu 22.04)
sudo bash infrastructure/setup.sh

# After DNS propagates (10-30 min):
certbot --nginx -d fadereach.app -d www.fadereach.app
certbot --nginx -d campaigns.tinlance.com
```

**DNS Records to add in Cloudflare:**
- A record: `@` → VPS IP
- A record: `mail` → VPS IP
- MX record: `@` → `mail.SENDING_DOMAIN`
- TXT record: `@` → SPF value
- TXT record: `mail._domainkey` → DKIM value (generated by setup.sh)
- TXT record: `_dmarc` → `v=DMARC1; p=none; rua=mailto:dmarc@SENDING_DOMAIN`

### ✅ Phase 1 — Internal Engine MVP (Week 2–4)
```bash
# Copy environment template
cp .env.example .env
# Fill all values in .env

# Start full stack
docker-compose up -d

# Import n8n workflow
# Go to n8n UI → Import from file → n8n-workflows/ai-personalization-pipeline.json

# Access internal Listmonk
# https://campaigns.tinlance.com
```
