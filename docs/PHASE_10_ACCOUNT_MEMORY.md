# Phase 10 — Account Memory

Phase 10 makes the account a persistent commercial memory object. Memory entries can represent facts, signals, hypotheses, objections, preferences, technologies, leadership changes, campaign/engagement state, outcomes, risks and relationships.

Memory is derivative, not authoritative: source systems and evidence remain canonical. Every memory entry carries confidence, evidence references, source references, validity bounds and a deterministic fingerprint so stale or contradictory memory can be superseded instead of silently overwritten.

## Phase gate

Persistent memory schema, provenance, deduplication, validity lifecycle, tenant isolation, refresh behavior, tests, documentation and all CI workflows must be green before Phase 11 starts.
