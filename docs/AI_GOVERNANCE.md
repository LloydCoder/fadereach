# AI Governance

## Authority
AI may summarize, classify, generate drafts, rank opportunities or recommend actions. Authoritative state, policy, authorization, suppression and execution remain deterministic system responsibilities.

## Data
External content is untrusted. Sensitive tenant data may only be sent to approved model providers under applicable data-processing configuration.

## Evaluation
AI features require evaluation for factuality, instruction-following, harmful automation, prompt injection resistance, tenant isolation and regression behavior.

High-impact outbound actions require configurable approval/autonomy gates. Emergency stop overrides model intent.
