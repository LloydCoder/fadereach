# Support and Escalation

## Escalate immediately
- suspected cross-tenant access
- unauthorized outbound activity
- credential compromise
- data loss/corruption
- persistent provider rejection
- failed recovery/restore
- compliance-sensitive incident

## Support record
Capture tenant, timestamp, symptoms, request/correlation IDs, deployment version, affected workflow and safe evidence. Never request passwords, API keys or full authentication tokens in support channels.

Security incidents follow Incident Response, not ordinary support handling.
