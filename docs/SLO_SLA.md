# SLO and SLA Policy

Internal SLOs are engineering targets. External SLAs are contractual promises and require operational evidence.

## Candidate SLOs
- API availability
- API latency
- webhook processing latency
- queue processing latency
- campaign execution success
- database availability
- recovery time

Targets must be selected after measurement and documented with windows, exclusions and error-budget policy. Do not advertise an SLA merely because CI is green.
