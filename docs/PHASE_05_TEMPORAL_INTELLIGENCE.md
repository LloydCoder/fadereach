# Phase 5 — Temporal Intelligence

Phase 5 models how signals evolve instead of treating events as timeless facts. The trajectory engine detects emergence, persistence, acceleration, deceleration, recurrence, reversal, inactivity and decay from ordered signal observations.

Temporal state is deterministic and inspectable: velocity, acceleration, recurrence count, age, trend score and confidence are stored with the trajectory rationale. A temporal state is an inference about signal behavior, not proof of buyer intent.

## Phase gate

Trajectory classification, recency/age handling, reversal detection, persistence, recurrence, canonical persistence, tenant RLS, tests, documentation and all CI workflows must be green before Phase 6 starts.
