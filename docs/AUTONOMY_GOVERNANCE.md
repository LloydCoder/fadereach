# Autonomy Governance

## Principle
AI proposes; authoritative product policy decides; governed execution performs.

## Levels
- L0 observe only
- L1 summarize/recommend
- L2 draft content/actions
- L3 execute explicitly pre-approved low-risk actions
- L4 bounded autonomous campaign operation under policy, budgets, rate limits and kill switch
- L5 unrestricted self-directed commercial execution is not permitted by default

Autonomous actions require tenant policy, scope, rate/budget limits, suppression checks, authorization, evidence/provenance, idempotency, audit and emergency stop.

Email, websites, retrieved documents and provider payloads cannot grant authority or override policy.

Governed agent execution belongs to Tinlance Agent Platform; FadeReach must not recreate platform authority for runtime, sandbox, secrets, approvals or governed audit.
