# Phase 8 — Opportunity Hypothesis Engine

Phase 8 turns converged signal and Why-Now evidence into a ranked commercial opportunity hypothesis. Each hypothesis records the account, problem statement, capability required, evidence, timing rationale, fit/impact/priority scores, confidence and unknowns.

The engine does not claim that an opportunity is a confirmed buying event. It is a structured, evidence-backed hypothesis that can be qualified by later human or system outcomes.

## Phase gate

Opportunity generation, deterministic ranking, Why-Now linkage, evidence lineage, duplicate prevention, tenant isolation, tests, documentation and all CI workflows must be green before Phase 9 starts.
